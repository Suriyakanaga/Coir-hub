# Coir-hub



# 🚀 CoirHub – Smart Business Management App

CoirHub is a lightweight, browser-based business management application designed to help small-scale business owners (like coir rope traders) manage their daily operations with simplicity and clarity.

This app is built with a strong focus on **ease of use**, especially for users who are not highly tech-savvy.

---

# 🌟 Key Features

## 🔐 Authentication System

* User Registration (Name, Phone, Language, Photo)
* Secure Login (no fake users allowed)
* Multi-user support (per device)
* Persistent sessions

---

## 👤 User Profile

* Edit Name & Phone Number
* Upload Profile Photo
* Language selection (multi-language ready)
* Theme preference saved per user

---

## 📊 Dashboard

* Welcome message with user identity
* Total Stock overview
* Sales & Purchase summary
* Pending payments tracking
* Clean and minimal UI

---

## 📦 Business Management

* Purchases tracking
* Sales tracking
* Payment tracking
* Auto stock calculation

---

## 🎨 Theme System

* Dark Mode (default)
* Light Mode (manual switch)
* System Auto Theme Detection
* User-specific theme persistence

---

## 🌍 Language Support

* Multi-language ready structure
* User can choose preferred language
* Designed for wider accessibility

---

# 🧠 Architecture (Current)

This version uses:

* **Frontend:** React (via CDN, single file)
* **Storage:** localStorage (device-based)
* **Hosting:** GitHub Pages

---

# ⚠️ Important Limitation (Current Version)

* Data is stored using **localStorage**
* This means:

  * Data is **device-specific**
  * Same user cannot access data across devices

👉 Example:

* Register on phone → works only on phone
* Login on desktop → shows "not registered"
